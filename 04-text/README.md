# HTML с нуля, урок 3. Текст на странице

Код из видеоурока: как размечать текст — заголовки, абзацы, переносы, выделение, цитаты, код и спецсимволы.

| Файл | Что внутри |
|---|---|
| `before.html` | Статья про кота Пикселя без тегов. Открой в браузере: пустые строки и лишние пробелы исчезли, всё слилось в одну строку |
| `index.html` | Та же статья после разметки: `h1`–`h3`, `p`, `br`, `hr`, `strong`, `em`, `mark`, `small`, `del`, `ins`, `blockquote`, `cite`, `q`, `code`, `pre`, `sup`, `sub`, `abbr`, комментарий и спецсимволы `&lt;`, `&gt;`, `&nbsp;` |
| `mistakes.html` | Ошибки новичка из урока. Над каждой — комментарий, что не так |

## Шпаргалка

| Тег | Зачем |
|---|---|
| `h1`…`h6` | заголовки по смыслу, а не по размеру; `h1` обычно один, ступеньки не пропускаем |
| `p` | абзац; лишние пробелы и переносы внутри браузер склеивает в один пробел |
| `br` | перенос строки, где он важен по смыслу: адрес, стихи |
| `hr` | смена темы |
| `strong`, `em` | важное и смысловое ударение |
| `b`, `i` | жирный и курсив без особого смысла: название, слово на другом языке |
| `mark`, `small` | подсветка и мелкий шрифт по смыслу (примечание) |
| `del`, `ins` | удалённый и добавленный текст: старая и новая цена |
| `blockquote`, `cite`, `q` | длинная цитата, источник, короткая цитата (кавычки ставит браузер) |
| `code`, `pre` | код в строке и код на несколько строк с сохранёнными пробелами |
| `sup`, `sub` | верхний и нижний индекс: м², H₂O |
| `abbr` | сокращение, расшифровка — в `title` |
| `&lt;` `&gt;` `&amp;` `&nbsp;` | `<`, `>`, `&` и неразрывный пробел |
| `<!-- -->` | комментарий: в браузере не виден, но его может прочитать любой |

## Как запустить

Скачай все файлы папки в одну папку и открой нужный `.html` в браузере. Ничего устанавливать не нужно.

## Попробуй сам

- Открой `before.html` и `index.html` рядом и сравни.
- Проверь `mistakes.html` в валидаторе <https://validator.w3.org/#validate_by_input>: вставь код и посмотри, какие ошибки он найдёт.
- Возьми любой текст — рецепт, статью о питомце или любимой игре — и размечай его по правилам урока. Выпиши свои заголовки отдельно: получилось понятное оглавление?
