# Урок 1. Первый сайт за 8 минут

Страница из видеоурока: заголовок, текст, ссылка-переход к разделу, оформление на CSS, адаптация под телефон и кнопка, которая переключает тёмную тему.

| Файл | Что в нём |
|---|---|
| `index.html` | структура страницы: заголовки, текст, ссылка и список |
| `style.css` | оформление: фон, карточка, кнопка, правило для маленьких экранов и тёмная тема |
| `script.js` | кнопка «Сменить тему» добавляет или убирает у страницы класс `dark` |

## Как запустить

Скачай все три файла в одну папку и открой `index.html` в браузере. Ничего устанавливать не нужно.

## Попробуй сам

- Поменяй заголовок и тексты на свои.
- Подбери свои цвета для фона в `style.css`, строка `background: linear-gradient(...)`.
- Добавь в «Мои суперсилы» ещё один пункт `<li>`.
- Придумай свои цвета для тёмной темы в правилах `.dark`.
