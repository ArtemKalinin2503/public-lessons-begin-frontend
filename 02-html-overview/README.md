# HTML с нуля, урок 1. Все главные теги

Страница «Кот Пиксель» из видеоурока. Она написана только на HTML, без CSS: так видно, как браузер показывает разметку сам по себе.

| Группа | Теги на странице |
|---|---|
| Каркас | `<!DOCTYPE html>`, `html`, `head`, `meta`, `title`, `body` |
| Текст | `h1`, `h2`, `h3`, `p`, `strong`, `em` |
| Списки | `ul`, `ol`, `li` |
| Ссылки | `a href` — на раздел страницы, на `photos.html` и на другой сайт |
| Картинки и медиа | `img` с `alt`, `video` с `controls` |
| Структура | `header`, `nav`, `main`, `section`, `footer` |
| Таблицы | `table`, `tr`, `th`, `td` |
| Формы | `form`, `label`, `input` (text, email, checkbox), `button` |

## Как запустить

Скачай все файлы папки в одну папку и открой `index.html` в браузере. Ничего устанавливать не нужно.

## Попробуй сам

- Замени кота Пикселя на своего питомца или героя: поменяй заголовки и тексты.
- Добавь в список «Что он умеет» ещё один пункт `<li>`.
- Добавь в таблицу строку со своим временем и занятием.
- Поменяй картинку: положи свой файл рядом и укажи его имя в `src`. Не забудь про `alt`.
- Специально испорти путь к картинке и посмотри, что покажет браузер.
