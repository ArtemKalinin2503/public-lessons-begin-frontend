# HTML с нуля, урок 2. Блочные и строчные элементы

Код из видеоурока: чем блочные элементы отличаются от строчных, что во что можно вкладывать и как собрать страницу из блоков до того, как браться за стили.

| Файл | Что внутри |
|---|---|
| `examples.html` | Все примеры урока. Голубые рамки показывают блочные элементы, оранжевые — строчные |
| `index.html` | Структура страницы из блоков: `header`, `nav`, `main` с карточками `div class="card"`, `footer`. Без стилей |
| `styled.html` + `style.css` | Тот же HTML, к которому подключён CSS. Сравни с `index.html`: разметка не изменилась |

## Как запустить

Скачай все файлы папки в одну папку и открой нужный `.html` в браузере. Ничего устанавливать не нужно.

## Попробуй сам

- В `examples.html` открой DevTools (F12) и найди абзац с `div` внутри: посмотри, как браузер его разрезал.
- Поменяй местами `header` и `footer` в `index.html` и обнови страницу.
- Добавь в `index.html` четвёртую карточку и открой `styled.html`: она сразу встанет в ряд.
- Нарисуй любимый сайт прямоугольниками и собери такую же структуру из блоков.
