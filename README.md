# Уроки frontend для начинающих

Код из видеоуроков образовательного центра «Код роста»: <https://kod-rosta.ru>

Каждый урок лежит в своей папке. Открой папку, посмотри код и попробуй поменять его сам.

| № | Урок | Папка |
|---|---|---|
| 1 | Создай свой первый сайт за 8 минут: HTML, CSS и JavaScript с нуля | [01-first-site](01-first-site) |

## Как скачать

Нажми зелёную кнопку **Code** вверху страницы → **Download ZIP**, затем распакуй архив.

## Как открыть

Открой файл `index.html` двойным щелчком: страница откроется в браузере.
Чтобы менять код, открой папку урока в редакторе, например в бесплатном [VS Code](https://code.visualstudio.com/).
После изменений сохрани файл и обнови страницу в браузере.
